# 最小の完成例

架空のプロジェクト「Port Check」を題材に、SPECとADRを1本ずつ完成させた例です。
目的は記述量と相互参照の見本を示すことで、このリポジトリにCLIの実装があるという意味ではありません。
日付・担当チーム・判断・適用版はすべて例示です。Activeは、この架空プロジェクト内で合意済みであることを表します。

1. [ポート番号検証CLIの仕様](spec/DEMO-GLOBAL-SPEC-0001-port-check.md): 要件、受け入れ条件、失敗時の扱いを短く記述しています。
2. [副作用のないCLIとして提供する判断](adr/DEMO-GLOBAL-ADR-0001-cli-interface.md): 理由、代替案、代償、見直し条件を記述しています。

新しい文書は`spec/`・`adr/`等の`_template.md`から作成してください。この例を雛形へ貼り付ける必要はありません。
この規模では独立した調査記録と用語集は不要と判断し、例も作成していません。
実文書のindexにこれらを現行仕様として載せず、必要なときだけ書き手向けREADMEから参照します。

## サンプル内の実装計画

この節は、架空プロジェクトにおける未実装事項の追跡先です。
実運用では、同様のタスクは利用中のIssue・PRに置きます。

- CLI本体を実装し、SPECの各要件IDを対応するテストから参照する。
- 正常値、境界値、不正入力、引数個数、ファイル・ネットワークへの副作用を検証する。
- v0.1.0の提供前に、SPECの検証参照を計画から実在するテストへのリンクへ更新する。

## 検査

ルートの検査コマンドは、この完成例も独立した文書群として検査します。
この案内、SPEC、ADRには未置換の記入欄も架空のリンク先も残していません。
