# ポート番号検証CLIの仕様

## 要約・適用対象

設定作業で入力したポート番号が、許可する整数範囲にあるかを検証する。
シェルから呼び出せるCLIとして、標準出力と終了コードで結果を返す。

- 適用対象: Port Check v0.1.0の`port-check`コマンド。
- 外部との境界: 呼び出し元のシェル、標準出力、標準エラー出力。
- 実装との差分: 全要件が未実装。[実装計画](../README.md)で追跡する。

## スコープ・非スコープ

対象: 引数1個の書式と値域の検証。

対象外: ポートの空き状況、接続可能性、サービス名の解決。

前提・制約: 引数はシェルで分割された後の文字列として扱う。

## 要件と受け入れ条件

| ID | 状態 | 規範要件 | 受け入れ基準 | 検証参照 |
|---|---|---|---|---|
| F001 | Current | 有効な引数1個を受け取った場合、その番号とLFを標準出力へ出し、標準エラー出力を空にして終了コード0を返す。 | `1`・`8080`・`65535`がそれぞれ同じ番号とLFを出し、終了コード0になる。 | 計画: 正常系と上下限のCLIテストを作成する。 |
| F002 | Current | 引数の個数・書式・値域が不正なら、標準出力を空にし、標準エラー出力へ`invalid port`とLFを出して終了コード2を返す。 | 引数なし、引数2個、`0`、`65536`、`01`、`+80`、`8.0`、`abc`、前後空白付き、全角数字で所定の出力と終了コードになる。 | 計画: 各不正入力のCLIテストを作成する。 |
| F003 | Current | 検証処理は、ファイルの作成・変更とネットワーク通信を行わない。 | 正常・異常系とも、ファイル書き込みと通信を禁止した環境でF001・F002を満たす。 | 計画: 副作用を禁止した環境での統合テストと実装レビューを行う。 |

## 外部契約・振る舞い

呼び出しは`port-check <port>`。有効な引数はASCII数字で先頭がゼロでない1〜5桁、値が1〜65535の文字列とする。
空白の除去や数値表現の補正はしない。出力はUTF-8、改行はLFとする。

構造・型の別の正本: なし。この文書を契約の正本とする。

状態は保持しない。入力不正時はF002の結果で終了し、再試行しない。
有効な番号でも、そのポートを実際に使用できることは保証しない。

## 設計判断・関連資料

設定の検証をシェルから独立して呼び出せるよう、[副作用のないCLIとして提供する](../adr/DEMO-GLOBAL-ADR-0001-cli-interface.md)。
