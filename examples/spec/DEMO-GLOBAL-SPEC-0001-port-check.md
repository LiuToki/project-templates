# ポート番号検証CLIの仕様

## 目的と範囲

設定作業で入力したポート番号が、許可する整数範囲にあるかを検証する。
シェルから呼び出せるCLIとして、標準出力と終了コードで結果を返す。

- 仕様を適用するもの: Port Checkの`port-check`コマンド。
- 対象版: v0.1.0。
- 実装との差分: 本仕様の振る舞いはすべて未実装。[実装計画](../README.md)で追跡する。

本書は、引数1個の書式・値域の判定と結果の返却を定める。ポートの空き状況、接続可能性、サービス名の解決は対象外とし、実環境の調査は行わない。有効な番号でも、そのポートを実際に使用できることは保証しない。

呼び出し元はシェル。引数はシェルで分割された後の文字列として受け取り、標準出力・標準エラー出力・終了コードで結果を返す。

## 関連仕様

関連する別のSPECや、構造・型を定義する別文書はない。本書を仕様の正本とする。

## 入力の判定

シェルから`port-check <port>`として呼び出されたとき、引数を検証する。有効な入力は引数1個であり、ASCII数字で先頭がゼロでない1〜5桁、値が1〜65535の文字列とする。空白の除去や数値表現の補正はしない。

## 結果の返却

有効な引数1個を受け取った場合、その番号とLFを標準出力へ出し、標準エラー出力を空にして終了コード0を返す。

引数の個数・書式・値域が不正なら、標準出力を空にし、標準エラー出力へ`invalid port`とLFを出して終了コード2を返す。

出力はUTF-8、改行はLFとする。

## 状態と副作用

状態は保持しない。入力不正時は所定のエラーを返して終了し、再試行しない。正常・異常のどちらの経路でも、ファイルの作成・変更とネットワーク通信を行わない。

## 設計判断・関連資料

設定の検証をシェルから独立して呼び出せるよう、[DEMO-GLOBAL-ADR-0001: 副作用のないCLIとして提供する判断](../adr/DEMO-GLOBAL-ADR-0001-cli-interface.md)に従う。
